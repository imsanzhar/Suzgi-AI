# 🧠 Suzgi AI

**Suzgi AI** — бұл стандартты қан және зәр талдаулары негізінде созылмалы бүйрек ауруының (СБА) қаупін ерте бағалауға арналған жасанды интеллект жүйесі.

---

## 🚀 Жоба туралы

Созылмалы бүйрек ауруы — жаһандық денсаулық сақтау жүйесіндегі маңызды мәселелердің бірі.  
2040 жылға қарай ол өлімнің 5-ші себебіне айналуы мүмкін.

Suzgi AI бұл мәселені шешу үшін:
- қолжетімді талдауларды пайдаланады  
- жасанды интеллект арқылы тәуекелді ерте анықтайды  
- дәрігерлерге шешім қабылдауға көмектеседі  

---

## ⚡ Негізгі мүмкіндіктер

- 🧠 **AI диагностика** — FT-Transformer + XGBoost гибридті моделі  
- 📊 **Жоғары дәлдік** — 93.8% accuracy  
- 🎯 **Сезімталдық** — 96.2% (ауруды жіберіп алмау)  
- 💸 **Өте арзан** — 1 диагностика = 4.5 теңге  
- 🚀 **Жылдам нәтиже** — бірнеше секунд  
- 🌍 **Қолжетімділік** — тек стандартты анализдер  

---
